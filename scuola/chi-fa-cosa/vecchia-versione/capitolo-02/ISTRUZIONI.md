# Capitolo 2 · Il nome — come metterlo sul sito

Pagine **17–26** del libro. Fai i passi in quest'ordine.

## 1. Il PDF
Admin → **Libri** → «Chi fa cosa?» → carica `build/chi-fa-cosa.pdf` (il libro intero, con il nuovo capitolo).
Attenzione: nel file la pagina 1 è la copertina, quindi il numero di pagina del file è **stampato + 1**.

## 2. Gli esercizi interattivi (16)
Admin → **Esercizi** → **Importa** → scegli «Chi fa cosa?» → carica `capitolo-02/esercizi.json`.
Codici: CFC-18 … CFC-34. Solo sul sito (non nel PDF): CFC-30.
Se un codice esiste già, viene aggiornato (non duplicato).

## 3. Audio
Admin → **Audio e video** → **Nuovo**:
| campo | valore |
|---|---|
| Codice | **CFC-33** |
| Tipo | si riconosce da solo dal file |
| Titolo | Luce alla Pescheria |
| Pagina | 24 |
| File | `capitolo-02/media/CFC-33-luce-alla-pescheria.mp3` |
| Testo | copia da `capitolo-02/media/CFC-33-luce-alla-pescheria.txt` (serve per chi non sente bene) |

Se vuoi la voce vera di Vlad: registra il racconto da Admin → Audio e video → **Registra** con lo stesso codice, al posto del file.

## 4. Video
Questo capitolo non ha video. Se vuoi aggiungerne uno (es. una lezione alla lavagna): Admin → **Lavagna e video**, registra, poi **Pubblica** con un codice della serie dei video: **CFC-901, CFC-902…** (così non si scontra con i codici dei capitoli futuri) e la pagina della lezione.

## 5. Controllo
1. Apri il libro nel lettore del sito, vai alle pagine 17–26.
2. Tocca 2–3 simboli ✎ e il simbolo ♪: devono aprirsi esercizio e audio.
3. Se un simbolo non si apre: Admin → **Scuola** → pulsante **Zone** del libro → disegna il riquadro a mano sulla pagina (ricorda: pagina del file = stampata + 1).
4. Prova un QR del PDF col telefono: deve aprire lo stesso esercizio.
